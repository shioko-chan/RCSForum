# RCSForum

一个面向飞书/抖音开放平台小程序运行时的论坛客户端，与 `RCSForum_Server` 后端配套使用。客户端通过 `tt.*` API 完成登录、网络请求、图片上传和本地存储。

## 功能

- 平台账号登录
- 主题浏览与发布
- 评论、点赞与取消点赞
- 匿名发帖
- 图片上传与展示
- 表情贴纸
- 用户主页
- 签到在线时长与排行榜
- 管理员删除内容

## 页面

```text
pages/
├── index/       # 主题列表
├── space/       # 用户空间
├── checkin/     # 签到与排行榜
├── newtopic/    # 发布主题
├── topic/       # 主题与评论详情
└── user/        # 用户信息
```

## 运行要求

- 飞书或抖音小程序开发者工具
- 已部署的 `RCSForum_Server`
- 对应开放平台应用的登录权限

## 配置后端地址

客户端后端地址当前在 `app.js` 中直接配置：

```js
url: "http://192.168.3.2"
```

导入项目后，应将其替换为实际 API 地址。真机或生产环境通常需要：

- 可从设备访问的域名或 IP
- HTTPS
- 在开放平台后台加入合法请求域名
- 与后端上传大小和超时设置保持一致

## 启动

1. 克隆仓库。
2. 在小程序开发者工具中导入仓库根目录。
3. 配置应用标识与权限。
4. 修改 `app.js` 中的后端地址。
5. 启动 `RCSForum_Server`。
6. 在模拟器或真机中编译运行。

项目不依赖常规浏览器 DOM，也不是普通 Web 应用，应在支持 `tt` API 的小程序环境中运行。

## 与后端的关系

客户端会调用后端完成：

- `/login` 平台身份交换
- 主题和评论的创建、读取、点赞及删除
- 图片上传和静态图片读取
- 用户资料与管理员状态查询
- 签到 keepalive 和排行榜查询

接口或认证字段发生变化时，需要同步修改前后端。

## 当前注意事项

- 后端地址硬编码在源码中，建议改为环境配置或构建配置。
- 当前开发地址使用明文 HTTP，仅适合可信局域网调试。
- 客户端会保存认证信息，应避免在日志中输出令牌。
- 上传文件、匿名内容和管理员操作仍应以后端权限校验为准，不能只依赖客户端界面控制。
